# Discord Bot Website Template (Free, HTML + CSS + JS)

A free, open-source **website template for Discord bots**: a landing page, an about page and a commands page, written in plain HTML, CSS and JavaScript. Swap in your bot's name, avatar, commands and invite link, then host it anywhere.

![Stars](https://img.shields.io/github/stars/Drix10/discord-bot-web?style=flat-square) ![Forks](https://img.shields.io/github/forks/Drix10/discord-bot-web?style=flat-square)

## Features

- Home page with bot avatar, tagline and invite / support buttons
- About page for your bot's story and team
- Commands page driven by `pages/commands.js`, easy to extend
- No framework and no build step; works on GitHub Pages, Netlify, Vercel or any static host

## Pages

| File | Page |
|---|---|
| `index.html`, `index.css`, `index.js` | Landing page |
| `pages/about.html`, `pages/about.css` | About |
| `pages/commands.html`, `pages/commands.css`, `pages/commands.js` | Command list |

## Get started

1. Clone the repository:
   ```bash
   git clone https://github.com/Drix10/discord-bot-web.git
   ```
2. Edit the bot name, commands and links in the HTML and `pages/commands.js`.
3. Replace `danime.png` with your bot's avatar.
4. Deploy the folder to any static host and open it in your browser.

Free to use and modify. A star helps others find it.
